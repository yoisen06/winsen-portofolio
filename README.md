# Winsen Cristiano Sun | Portfolio

Static portfolio site (HTML, CSS, JS) based on the open-source template by Syed Mohsin
(https://github.com/devsyedmohsin/portfolio-template).

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the folder to Netlify, Vercel, GitHub Pages or Cloudflare Pages. No build step needed.
